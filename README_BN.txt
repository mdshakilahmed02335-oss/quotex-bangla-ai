# Quotex বাংলা AI Trading Assistant — Web Prototype

## ব্যবহার
1. `index.html` ফাইলটি Chrome বা Edge-এ খুলুন। Screen Share API চালাতে HTTPS বা localhost প্রয়োজন।
2. Quotex ওয়েবসাইটটি আলাদা ট্যাবে খুলে লগইন করুন।
3. Assistant ট্যাবে ফিরে **স্ক্রিন শেয়ার শুরু** চাপুন।
4. Browser picker-এ Quotex tab নির্বাচন করুন এবং Share দিন।
5. RSI, MACD, Trend ও Support/Resistance চার্ট দেখে নিজে ইনপুট দিন; **বাংলায় বিশ্লেষণ করুন** চাপুন।
6. প্রথমে Quotex Demo account-এ পরীক্ষা করুন। এই টুলে signal log আছে, কিন্তু স্বয়ংক্রিয় trade execution নেই।

## অনলাইনে প্রকাশ (সহজ)
- GitHub account-এ একটি নতুন repository তৈরি করুন।
- `index.html` আপলোড করুন।
- Repository Settings → Pages → Deploy from a branch → `main` / root নির্বাচন করুন।
- GitHub Pages URL খুলুন। Screen share-এর জন্য অবশ্যই HTTPS URL ব্যবহার করুন।

## গুরুত্বপূর্ণ
এটি পূর্ণাঙ্গ AI নয়; স্ক্রিনে দেখা ক্যান্ডেল/ইন্ডিকেটর নিজে শনাক্ত বা লাইভ মার্কেট ডেটা বিশ্লেষণ করে না। RSI/MACD/Trend হাতে ইনপুট দিলে স্বচ্ছ, সরল rule-based স্কোর দেখায়। কোনো সিগন্যাল নিশ্চিত নয়। Quotex-এ কোনো অর্ডার দেয় না, broker login/API key চায় না, ভিডিও আপলোড করে না।”
